# @remkoj/optimizely-cms-api

- **Path:** `packages/optimizely-cms-api`
- **Module:** CommonJS
- **Build tool:** `tsc` + `@hey-api/openapi-ts`
- **Node:** none

## Scripts

| Script | Command |
| --- | --- |
| `prepare` | `tsc --build && node scripts/copy-client.mjs` |
| `watch` | `tsc --watch` |
| `clean` | `rimraf ./dist ./src/client ./*.tsbuildinfo` |
| `recompile` | `clean` + `generate` + `tsc --build --force` |
| `generate` | `node scripts/create-client.mjs` |

`recompile` runs the full cycle: cleans `dist/` and `src/client/`, regenerates the client, then force-rebuilds. This integrates correctly with `yarn recompile` at the repo root.

## Generated files

`src/client/**` is generated by `scripts/create-client.mjs` (`@hey-api/openapi-ts`) from the CMS OpenAPI spec. Files end in `.gen.ts`. Do not hand-edit — overwritten on every `generate` run.

`clean` removes `src/client/` in addition to `dist/`; after `clean`, run `generate` before `prepare`.

```bash
yarn workspace @remkoj/optimizely-cms-api run rebuild
```
