# @remkoj/optimizely-graph-client

- **Path:** `packages/optimizely-graph-client`
- **Module:** ESM
- **Build tool:** `tsc`
- **Node:** none

## Scripts

| Script | Command |
| --- | --- |
| `prepare` | `node scripts/update-cfg.mjs && tsc --build` |
| `compile-ts` | same as `prepare` |
| `watch` | `tsc --watch` |
| `clean` | `tsc --build --clean` |
| `recompile` | `tsc --build --clean && tsc --build --force` |
| `generate` | regenerate `src/admin-api/client/**` from live swagger, then run `update-imports` |
| `update-imports` | `node scripts/update-imports.mjs` |

## Subpath exports

| Export | Contents |
| --- | --- |
| `.` | Graph client and core types |
| `./client` | GraphQL query client |
| `./config` | configuration helpers |
| `./router` | content routing utilities |
| `./channels` | channel/site management |
| `./admin` | Admin API client (generated) |
| `./codegen` | codegen integration helpers |
| `./utils` | shared utilities |

## Generated files

`src/admin-api/client/**` is generated by `openapi-typescript-codegen` from:
```
https://cg.optimizely.com/app/swagger/swagger.json
```
Do not hand-edit — overwritten on every `generate` run. `generate` runs `update-imports` automatically.

```bash
yarn workspace @remkoj/optimizely-graph-client run generate
yarn workspace @remkoj/optimizely-graph-client run prepare
```
